Audio Formats

UVR supports various audio formats for input and output.

Input Formats

  • WAV: Uncompressed, best quality
  • FLAC: Lossless compression
  • MP3: Lossy compression
  • M4A/AAC: Apple formats
  • OGG: Open source format
  • WMA: Windows Media Audio

Output Formats

  • WAV (Recommended):
    • PCM 16-bit: Standard quality
    • PCM 24-bit: Higher quality
    • PCM 32-bit: Maximum quality
    • Float 32-bit: Professional use
    • Float 64-bit: Maximum precision (double)
  • FLAC: Lossless compression, smaller files
  • MP3: Compatible, adjustable bitrate (128-320 kbps)
Format Recommendations:
• Archival: Use WAV 24-bit or FLAC
• Editing: Use WAV 32-bit float
• Sharing: Use MP3 320kbps
• Storage-conscious: Use FLAC
• Maximum precision: Use WAV 64-bit float
