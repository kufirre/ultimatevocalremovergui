Ensemble Mode

Combine multiple models for superior results.

What is Ensemble Mode?

Ensemble mode processes audio through multiple models and combines the results, often achieving better separation than any single model.

Creating Ensembles

  1. Select "Ensemble Mode" from the process method
  2. Choose models to include
  3. Select combination algorithm
  4. Save ensemble for reuse

Combination Algorithms

  • Average: Simple average of all models
  • Weighted Average: Custom weights per model
  • Min/Max: Take minimum or maximum values
  • Median: Median value across models
Best Practices:
• Combine models with different strengths
• Use 2-4 models for best balance
• Test different algorithms for your content
• Save successful ensembles for reuse
Performance Note: Ensemble processing time equals the sum of all included models. Plan accordingly for large batches.
