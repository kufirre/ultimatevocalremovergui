Getting Started with UVR

Welcome to Ultimate Vocal Remover! This guide will help you get started with audio source separation.

Quick Start

  1. Select Input Files: Click "Select Input" to choose audio files
  2. Choose Output Folder: Click "Select Output" to set destination
  3. Select Model: Choose a separation model from the dropdown
  4. Start Processing: Click "Start Processing" to begin

First Time Setup

On first run, UVR will:

  • Create necessary directories
  • Download required models (if selected)
  • Configure default settings
Note: First-time model downloads may take several minutes depending on your internet connection.

Tips for Best Results

  • Use high-quality input files (WAV or FLAC recommended)
  • Ensure adequate disk space for output files
  • Enable GPU acceleration if available
  • Experiment with different models for your content
  • Try Karaoke models for vocal splitting and background vocal removal
  • Use Ensemble Mode to combine multiple models for better results
  • Consider VIP access for premium models and features

Model Selection Guide

  • VR Architecture: Fast, good for vocals/instrumentals, karaoke models available
  • MDX-Net: High quality, good instrumental separation
  • Demucs: Best for 4-stem separation (vocals, drums, bass, other)
  • Ensemble: Combines multiple models for superior results
