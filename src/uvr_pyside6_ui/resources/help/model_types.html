Model Types

UVR supports several model architectures, each with unique strengths:

VR Architecture

Vocal Remover models - Original UVR architecture

  • Fast processing speed
  • Good for vocals/instrumental separation
  • Lower memory requirements
  • Supports model ensembling
  • Karaoke models available - Special models for vocal splitting and lead/backing vocal separation
  • BV models - Background vocal removal models

MDX-Net

Music Demixing Challenge models - Advanced neural networks

  • High quality separation
  • Multiple stem support
  • Larger model sizes
  • GPU recommended

Demucs

Facebook's Demucs - State-of-the-art separation

  • Excellent quality
  • 4-stem separation (vocals, drums, bass, other)
  • High memory usage
  • Slower processing
Choosing the Right Model:
• Quality vs Speed: Demucs for quality, VR for speed
• Memory: VR uses least, Demucs uses most
• Stems needed: Use Demucs for 4-stem separation
• Hardware: GPU greatly speeds up MDX-Net and Demucs
• Karaoke/Vocal Splitting: Look for karaoke or BV models in VR Architecture
• Professional Use: Consider VIP access for premium models

VIP Models

Premium Models - Exclusive access for supporters

  • Enhanced quality over free models
  • Early access to experimental models
  • Commercial usage rights
  • Available across all architectures (VR, MDX-Net, Demucs)
  • Cryptographic verification required
