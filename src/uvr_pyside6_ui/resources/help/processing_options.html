Processing Options

Customize your separation with these options:

Basic Options

  • Save Format: Output format (WAV, FLAC, MP3)
  • Sample Rate: Output sample rate (match source recommended)
  • Normalization: Normalize output volume
  • Clip Guard: Prevent audio clipping

Advanced Options

  • TTA (Test-Time Augmentation): Improves quality, slower processing
  • Post-Process: Additional cleanup pass
  • High-End Process: Maximum quality mode
  • Batch Size: Processing chunk size (affects memory/speed)

Model-Specific Options

VR Architecture:

  • Window Size: Affects frequency resolution
  • Aggression: Separation strength (1-20)

MDX-Net:

  • Segment Size: Processing segment length
  • Overlap: Segment overlap amount
  • Denoise: MDX-specific denoising

Demucs:

  • Segment: Chunk duration
  • Shifts: Number of prediction shifts
  • Split Mode: Frequency/time domain split
