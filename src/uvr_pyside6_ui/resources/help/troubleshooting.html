Troubleshooting

Common issues and their solutions:

Performance Issues

Problem: Processing is very slow

  • Enable GPU acceleration if available
  • Reduce batch size in advanced settings
  • Lower segment size for MDX-Net models
  • Close other applications to free memory
  • Use VR Architecture for faster (but lower quality) results

Problem: Out of memory errors

  • Reduce batch size to 1 or 2
  • Use CPU mode instead of GPU
  • Process shorter segments (trim long files)
  • Close other applications
  • Restart the application to clear memory

Audio Quality Issues

Problem: Poor separation quality

  • Try different models - quality varies by content
  • Enable TTA for better quality (slower)
  • Use Ensemble Mode to combine multiple models
  • Enable Post-Process in advanced settings
  • Check your input file quality - use WAV/FLAC

Problem: Audio artifacts or distortion

  • Lower aggression setting for VR models
  • Enable High-End Process
  • Try different overlap settings for MDX-Net
  • Use different model architecture

Model Issues

Problem: Model not found or won't load

  • Check model file location - ensure it's in correct folder
  • Re-download the model if corrupted
  • Verify model compatibility with your UVR version
  • Check file permissions - ensure UVR can read files

File Issues

Problem: Can't load input file

  • Check file format - WAV, FLAC, MP3, OGG supported
  • Try converting to WAV first
  • Check file permissions
  • Ensure file isn't corrupted

Problem: Output files not created

  • Check output folder permissions
  • Ensure enough disk space
  • Check if antivirus is blocking
  • Try different output location
Still having issues?
Check the Error Log (Help → View Error Log) for detailed error messages.
Consider reporting bugs through the official UVR channels.
